## 🎯 Overview

The GrwoFinance Tax Compliance module helps Nigerian businesses manage their tax obligations efficiently and stay compliant with Federal Inland Revenue Service (FIRS) regulations. This comprehensive system provides tools for tracking VAT, WHT, PAYE, and other tax requirements.

### 🚀 Key Features

- **FIRS Compliance Monitoring**: Real-time compliance status tracking
- **Tax Calendar**: Automated deadline reminders and filing schedules
- **Report Generation**: One-click tax report creation
- **Receipt Management**: Digital receipt storage and organization
- **WHT Tracking**: Withholding tax certificate management
- **Nigerian Tax Support**: VAT (7.5%), WHT, PAYE, and CIT calculations

## 🚀 Getting Started

### Prerequisites

- Active GrwoFinance account
- Business registration details
- Tax identification number (TIN)
- Internet connection

### First Login

1. Navigate to the GrwoFinance login page

## 📈 WHT Tracking

### WHT Overview

Withholding Tax (WHT) is a critical Nigerian tax requirement:

#### **WHT Types**

- **Contract WHT**: 5% on contracts
- **Rental WHT**: 10% on rentals
- **Interest WHT**: 10% on interest
- **Dividend WHT**: 10% on dividends
- **Royalty WHT**: 5% on royalties
- **Commission WHT**: 5% on commissions
- **Directors' Fees**: 10% on directors' fees

### WHT Process

#### **Deduction Phase**

1. **Contract Analysis**: Review contracts for WHT applicability
2. **Rate Determination**: Calculate correct WHT rate
3. **Amount Calculation**: Calculate WHT amount
4 **Deduction**: Deduct WHT from payments
5. **Documentation**: Issue WHT deduction certificates

#### **Remittance Phase**

1. **Payment Processing**: Process payments to contractors
2. **WHT Remittance**: Remit WHT to FIRS
3. **Remittance Evidence**: Collect remittance evidence
4. **Record Keeping**: Update WHT records
5. **Status Updates**: Track remittance status

#### **Certification Phase**

1. **Certificate Request**: Request WHT certificates
2. **Certificate Issuance**: Receive certificates from FIRS
3. **Certificate Storage**: Store certificates securely
4. **Certificate Sharing**: Share certificates with contractors
5. **Status Updates**: Update certificate status

## 🔧 Troubleshooting

### Common Issues

#### **Login Issues**

**Problem**: Cannot log in to tax compliance
**Solution**:
1. Verify email and password
2. Check internet connection
3. Clear browser cache
4. Contact support if needed

#### **Data Loading Issues**

**Problem**: Tax compliance data not loading
**Solution**:
1. Refresh the page
2. Check internet connection
3. Verify user permissions
4. Check server status

#### **Report Generation Issues**

**Problem**: Reports not generating
**Solution**:
1. Check required fields
2. Verify data accuracy
3. Check file permissions
4. Try different format

#### **File Upload Issues**

**Problem**: Cannot upload receipts
**Solution**:
1. Check file format (PDF, JPG, PNG)
2. Check file size (max 10MB)
3. Check internet connection
4. Try smaller files

#### **Permission Issues**

**Problem**: Access denied errors
**Solution**:
1. Verify user role
2. Check user permissions
3. Contact administrator
4. Request access if needed

### Error Messages

#### **Authentication Errors**

- **"Authentication Required"**: Login required
- **"Invalid Token"**: Token expired, re-login
- **"Access Denied"**: Insufficient permissions

#### **Validation Errors**

- **"Validation Error"**: Check required fields

- **"Invalid Date"**: Check date format

#### **System Errors**

- **"Server Error": Try again later

## ❓ FAQ

### General Questions

**Q: What tax types does GrwoFinance support?**
A: GrwoFinance supports VAT (7.5%), WHT (5-10%), PAYE, and CIT calculations for Nigerian businesses.

**Q: How often should I file tax returns?**
A: VAT returns are monthly, PAYE is monthly, WHT certificates are required as needed, and annual returns are due by December 31st.

**Q: Can I generate historical reports?**
A: Yes, you can generate reports for any historical period within your data retention period.

**Q: How secure is my tax data?**
A: All tax data is encrypted and access is controlled by user permissions and roles.

### Technical Questions

**Q: What browsers are supported?**
A: GrwoFinance supports all modern browsers including Chrome, Firefox, Safari, and Edge.

**Q: Can I export my data?**
A: Yes, you can export reports in PDF, Excel, or CSV format for external use.

**Q: Is mobile access available?**
A: Yes, GrwoFinance is fully mobile-responsive for tax compliance management.

**Q: Can I customize the tax calendar?**

**Q: Is the system FIRS-compliant?**
